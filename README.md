
## Ключові функції

### useVoiceRecorder
Записує аудіо через `expo-av`. Автоматично визначає голос по порогу гучності (`metering > -37 dB`). Після 1с тиші — зупиняє запис і повертає URI файлу + часові мітки початку/кінця мовлення.

### useAudioPlayback
Відтворює записаний файл через `expo-av` зі зміненою швидкістю (`rate: 1.5`, `shouldCorrectPitch: false` — ефект чіпмонка). Підтримує відтворення з позиції та автозупинку на кінці мовлення.

### flowReducer
Чиста функція що керує переходами стану: `monitoring → recording → playing → monitoring`. Гарантує що неможливі невалідні переходи (наприклад, з `monitoring` відразу в `playing`)

### useTalkingTomFlow
Головний хук-оркестратор. Використовує `useReducer(flowReducer)` + callbacks від підхуків. Керує повним циклом: дозвіл → моніторинг → запис → відтворення → повтор.

### Обрізка тиші при відтворенні
Запис починається під час моніторингу (для metering). Щоб не програвати тишу до та після мовлення — відстежуємо момент початку та кінця голосу, програємо тільки цей відрізок через `playFromPositionAsync`.
